# 🍟 麦门聚餐管家（mcd-party-meal-planner）

> 仓库名：`mcd-party-skill` ｜ 技能名：`mcd-party-meal-planner` ｜ 当前版本：v1.1.2
> **多人麦当劳聚餐，选店、按预算出三套方案、官方核价、派对预约，一键理清。**

一款基于 **麦当劳 MCP** 开发的 WorkBuddy Skill：几个人一起吃麦当劳时，帮你选门店、按预算排出「经济 / 均衡 / 丰盛」三套方案，用官方接口整单核价，还能查派对预约信息。不让你自己对着菜单一个个算，也不用担心算错。

## 能力清单

- 🏪 **选店**：按城市/位置查附近麦当劳门店，展示地址、距离，帮你选一家
- 💰 **按预算出三套方案**：经济型 / 均衡型 / 丰盛型，每人能吃到啥、人均多少、是否超预算，一目了然
- ✅ **官方核价**：每套方案都用麦当劳官方 `calculate-price` 接口整单核价，不拿菜单价瞎加减，价格可信
- 🧮 **优惠叠加**：自动查门店券/卡包/可领未领券/当月活动日历，把能用上的优惠全叠进方案，核价对比取最省，省了多少明说
- 🎉 **派对预约信息**：按城市→门店→日期→场次四级查派对，给可预约时间/人数/价格（只查信息，不代下单）
- 🧮 **自动算人均**：总价÷人数自动算好，改人数/改预算后自动重算重核价
- 🛡️ **只读不下单**：全程只出方案和预约信息，不碰支付、不真实下单

## 安装方法

1. **申请 MCP Token**：打开 [open.mcd.cn/mcp](https://open.mcd.cn/mcp)，用手机号登录 → 右上角「控制台」→「激活」，获取 MCP Token。
2. **配置 WorkBuddy 连接器**：在连接器里添加 `mcd-mcp`（type=streamablehttp，url=https://mcp.mcd.cn，Authorization 填 Bearer Token）。Token 只走环境变量 `MCD_MCP_TOKEN`，绝不写进代码/仓库。
3. **加载本 Skill**：把本仓库的 `SKILL.md` 作为 WorkBuddy Skill 加载（或导入 skills 目录），重启后即可触发。
4. **开聊**：直接说「4 个人聚餐，预算 120，在上海」，Skill 会自动接管整个流程。

### 命令行方式（可选）

```bash
export MCD_MCP_TOKEN=你的Token   # Windows PowerShell: $env:MCD_MCP_TOKEN="你的Token"
python scripts/party_planner.py --city 上海 --keyword 人民广场 --people 4 --budget 120 --taste 随便
```

> - **均衡型 118.5 元**：人均 29.6，板烧鸡腿堡三件套×2 + 麦麦周末双人餐，刚好在预算内 ✅

> 想换人数/预算告诉我，我重新核价。

## 实测记录

一次真实的官方核价结果（脱敏，城市=上海）：

| 餐品 | 数量 | 单价(元) |
|------|:--:|:--:|
| 麦乐鸡经典中套餐 | 2 | 25.5 |
| 麦麦周末双人餐 | 1 | 49.9 |

- **接口核价返回**：`price = 10090`（分）→ **100.9 元**
- **验算**：25.5×2 + 49.9×1 = 100.9 元 ✅ 与官方核价一致
- **4 人场景**：人均 25.23 元，经济型、不超 120 元预算

一次真实的叠券核价结果（西安金地广场餐厅，storeCode=1960632，到店自取）：

| 档位 | 无券核价 | 叠券核价 | 省 | 人均 | 超预算 |
|---|---:|---:|---:|---:|---|
| 经济型 | 69.90 | **78.20**（多含美式中杯×1） | 5.70 | 26.07 | 否 ✅ |
| 均衡型 | 100.40 | **94.70**（结构调整：可乐×3→×2、香肠×2→×1，多含美式券） | 5.70 | 31.57 | 否 ✅ |
| 丰盛型 | 136.40 | **149.70**（多含美式中杯×1） | 5.70 | 49.90 | 是 ⚠️（超 47.70） |

> 用「新人专享-中杯美式7折」券，美式中杯 19→13.3；券通过 `couponId/couponCode` 传入核价，`saved` = 原价合计 − 叠加后总价。

> 说明：所有方案价格均以麦当劳官方 `calculate-price` 实时核价为准，非人工估算。

## 工程约定

- 任何餐品组合变化都必须重新调用 `calculate-price` 整单核价，禁止用菜单显示价拼凑
- 接口失败即停：不猜价格、不自动重试（仅 HTTP 429 做指数退避）
- 所有写操作默认 `dry_run`，显式 `--confirm` 才真实调用
- Token 只走环境变量 `MCD_MCP_TOKEN`
